## Featured Project

### [Personal Engineering Portfolio Website](https://github.com/THARANESHSELVAM/Personal-Portfolio-Website)

* **Repository:** [github.com/THARANESHSELVAM/Personal-Portfolio-Website](https://github.com/THARANESHSELVAM/Personal-Portfolio-Website)
* **Live Deployment:** [personal-portfolio-website-nine-lac.vercel.app](https://personal-portfolio-website-nine-lac.vercel.app/)

#### Overview
An interactive web application built to document my software projects, engineering diary milestones, and dynamic résumé. I developed this portfolio to provide recruiters and engineering teams with an open, accessible demonstration of what I am learning and building.

#### What Visitors Can Explore
* **Recruiter-First Public Landing Page:** Immediate visibility into project summaries, technical focus areas, and verified educational credentials with zero login gates.
* **Interactive Case Study Modals:** Structured project articles detailing problem statements, technical rationale, and architectural trade-offs.
* **Dynamic Plain-Text Résumé:** Client-side résumé generation compiled on the fly from verified project and milestone data.
* **Interactive Demo Workspace:** A dedicated sandboxed route (`/workspace`) for testing milestone logging and client-side data persistence.

#### Technology Stack (Declared by Project)
* **Framework:** Next.js 16 (App Router)
* **UI Library:** React 19
* **Language:** TypeScript (Strict Mode)
* **Styling:** Tailwind CSS v4
* **Deployment:** Vercel Edge

#### What I Am Learning Through This Project
Developing this project has helped me understand component-driven UI architecture, React 19 client/server boundaries, strict TypeScript typing, responsive design principles, and working with Git during development. 

*(Development Workflow Note: This application was developed with the assistance of Antigravity, an AI-assisted development environment. My focus throughout the project has been on iterative prompting, testing, reviewing generated code, validating state persistence, and strengthening my understanding of the underlying framework.)*
