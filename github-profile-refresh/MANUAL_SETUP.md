# Step-by-Step Manual Setup Guide

Follow this guide to apply the refined profile and repository settings directly on GitHub.

---

## Understanding the Two Repositories

Before beginning, note the distinction between your two repositories:

1. **`Personal-Portfolio-Website` (Existing Codebase):**  
   This is your actual Next.js 16/React 19 portfolio application. You do **not** replace this repository's README with your personal profile README.
2. **`THARANESHSELVAM` (Special Profile Repository to be Created):**  
   GitHub has a feature where creating a public repository whose name matches your username (`THARANESHSELVAM`) displays its root `README.md` at the very top of your public profile page (`https://github.com/THARANESHSELVAM`).

## Step 1: Create Your GitHub Profile README Repository

1. Open your browser and go to: **[https://github.com/new](https://github.com/new)**
2. In the **Repository name** field, type exactly:
   ```text
   THARANESHSELVAM
   ```
   *(GitHub will show a callout box confirming: "✨ You found a secret! THARANESHSELVAM/THARANESHSELVAM is a ✨special✨ repository that you can use to add a README.md to your GitHub profile.")*
3. Set the visibility to: **Public** *(required for profile READMEs)*.
4. Check the box: **Add a README file**.
5. Click **Create repository**.
6. On the new repository's page, open `README.md` and click the **pencil icon ✏️ (Edit this file)**.
7. Replace all existing text with the exact contents of:
   ```text
   github-profile-refresh/README.md
   ```
8. Click **Commit changes...**, enter a commit message like `feat: initialize minimal professional profile README`, and confirm.
9. Visit **[https://github.com/THARANESHSELVAM](https://github.com/THARANESHSELVAM)** to verify your new profile presentation.
